# SmartGeoAI — Main Navigation Integration v1

Bu patch master loyihadagi fayllarni to'liq almashtirmaydi. Patch skripti mavjud fayllarga faqat kerakli navigatsiya bloklarini qo'shadi va avval backup yaratadi.

## Yangi fayllar
- `dashboard/platform_views.py`
- `templates/superadmin/platform_center.html`
- `templates/superadmin/gsor_center.html`
- `tools/apply_main_navigation_integration.py`

## O'rnatish
ZIP tarkibini `workflow2` ichiga ko'chiring, so'ng:

```powershell
.\venv\Scripts\python.exe .\tools\apply_main_navigation_integration.py
.\venv\Scripts\python.exe manage.py check
.\venv\Scripts\python.exe manage.py runserver
```
