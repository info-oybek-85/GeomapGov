SmartGeoAI Organization Workflow V2

Qo'shilgan imkoniyatlar:
1. Ijrochi "Ishni boshlash" orqali vaqtni qayd etadi.
2. Ishni yakunlashda kamida bitta foto/video/PDF dalil yuklaydi.
3. Dalillar murojaat tafsilotida ko'rinadi.
4. Har bir fayl uchun 15 MB cheklov mavjud.
5. Murojaat "Fuqaro tasdig'i kutilmoqda" holatiga o'tadi.
6. Tashkilot administratori tasdiqlaydi yoki qayta ishga yuboradi.
7. Rahbar dashboardida muddati o'tgan, tasdiq kutilayotgan va bugun hal qilingan murojaatlar ko'rinadi.
8. O'rtacha qabul qilish, ijro va umumiy hal etish vaqti hisoblanadi.

Ishga tushirish:
python manage.py migrate
python manage.py check
python manage.py runserver

Bot alohida terminalda:
cd bot
python main.py
